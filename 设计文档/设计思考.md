## 一、先定 3 个关键判断

1. **三级大纲模型**：总纲（主线）→ 卷纲（一个阶段的事件序列）→ 章纲（每章 3—7 个 beat）。你的例子里“得到第一只兽宠、参加宝宝赛、晋升学府、战异兽皇……”属于**卷纲事件**，需要 AI 先拆成章纲，人确认后再写正文。
2. **拆章纲按“卷”批量做**：一次拆一个阶段（约 15—40 章），用户批量确认/微调，再逐章生成。不要一章一章问，效率太低。
3. **模型选型**：DeepSeek / 通义 / 豆包 / Kimi 这类国产模型，32k—128k 上下文，单章成本约 0.1—0.3 元。一个月写 100 章，API 成本约 20—40 元，50—100 元预算够用，还能留出自检和重生成余量。**不要用 GPT-4o/Claude 做主生成**，成本会超。

## 二、PRD 骨架

**产品名（暂定）**：长篇小说 AI 创作台
**一句话**：导入主线与阶段大纲，AI 拆章纲，人确认后逐章流式生成 2500 字，改完自动回写摘要与设定，保证长篇不崩。

### 功能模块

| 模块      | P0 内容                                                      |
| :-------- | :----------------------------------------------------------- |
| 账号/作品 | 登录、作品列表、新建、删除、状态                             |
| 大纲      | 总纲编辑、卷纲（阶段事件列表）、AI 拆章纲、章纲确认          |
| 设定库    | 角色卡、世界观、时间线、伏笔、文风卡；AI 从大纲抽初稿 + 人工补充 |
| 章节      | 章节列表、状态机（未生成/生成中/待审/已审）、Markdown 编辑、版本历史 |
| 生成      | 单章流式生成、分段生成、停止/继续、重生成、字数控制 2300—2700 |
| 审核      | 一致性自检、章摘要草稿、状态变更草稿、人工确认入库           |
| 导出      | 单章/整卷/全书导出 docx，保留标题层级                        |

### 章节状态机

`未生成 → 生成中 → 待审核 → 已审核 → 已导出`；退回则回 `未生成/待审核`。

## 三、页面原型文字稿

### 1. 作品工作台（首页）

- 顶部：作品名、总字数、已审核章数、本月已用额度。
- 左栏 Tab：**设定库 / 大纲 / 章节 / 导出**。
- 大纲页：上半“总纲”文本域；下半“卷列表”，每卷一行：卷名、事件数、章数、状态（未拆/待确认/已确认）；按钮“AI 拆本章纲”。
- 设定库：分 Tab 角色/世界观/时间线/伏笔/文风，卡片式增删改，每张卡有“来源：AI 初稿/人工”。

### 2. 卷纲确认页（核心新增页）

- 左：本卷事件序列（你写的那串“得到第一只兽宠→宝宝赛→学府大比……”）。
- 右：AI 生成的章纲列表，每行：章号、章名、3—7 个 beat、涉及角色、预计字数。
- 操作：单章编辑、删除、插入、拖拽排序、“重新生成本卷章纲”、“确认本卷”。
- 确认后章节自动进入章节列表，状态“未生成”。

### 3. 章节创作页（最重要）

三栏：

- 左：章节树 + 本章章纲 + 本章引用设定卡（可点开）。
- 中：Markdown 编辑器。点“生成本章”后正文逐句流式追加，显示“生成中 1200/2500 字”，有“停止/继续/重生成”。生成完可编辑，自动保存。
- 右：AI 面板 —— “一致性自检”“生成摘要”“重新摘要”“局部重写选中段落”；下方显示自检问题列表（位置+建议）。
- 底部状态栏：待审核 → 点“提交审核”。

### 4. 审核页

- 左：正文预览。右：AI 自检问题、章摘要草稿（200—300 字）、状态变更草稿（角色等级/新宠/时间线事件/伏笔）、字数。
- 按钮：**通过并入库**（写回摘要/时间线/伏笔）/ **退回修改**。
- 入库后本章状态“已审核”，下一章可生成。

```

4. 不得新增设定库外的关键角色/地名；确需新增，列在"待新增设定"里。

【总纲】{{main_outline}}
【本卷事件】{{volume_events}}
【设定库摘要】{{settings_digest}}
```



### B. 生成正文（分段调用，每段 400—600 字）

text

```
你是网文作者，用第三人称、正能量、有深度的风格续写。
【文风卡】{{style_card}}
【本章章纲】{{chapter_beats}}
【相关角色卡】{{characters}}
【世界观/时间线/伏笔】{{world_timeline}}
【前情摘要】全书：{{book_sum}}；本卷：{{vol_sum}}；前3章：{{prev_sums}}
【上一段结尾】{{last_paragraph}}
任务：写第 {{seg_no}}/{{seg_total}} 段，400—600 字，承接上文，只推进本段对应 beat，结尾留自然钩子。
禁止：新增设定库外关键角色/地名；改变人称；让角色知道未发生的信息；写敏感内容。
```

text

```

输出 JSON：[{"type":"","quote":"","issue":"","suggest":""}]，无问题返回 []。
【正文】{{chapter_text}}
```

## 六、成本核算（按 100 章/月）

单章：分段生成 5 次 × 输入约 6k + 输出 0.8k，加一次自检、一次摘要，合计输入约 35k、输出约 6k tokens。国产模型约 **0.08—0.2 元/章**，100 章 **10—20 元/月**，重生成和拆章纲再加 10—20 元。**50—100 元预算充足**，可留出升级 128k 上下文的余量。
